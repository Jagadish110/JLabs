04 AI CODE REVIEW

CodeSafe

NEXT.JS · TYPESCRIPT · GOOGLE GEMINI · TREE-SITTER · SUPABASE

A security scanner for AI-generated code. Six specialist AI agents scan a codebase in parallel — each covering one domain: secrets, authentication, injection, cryptography, AI anti-patterns and production readiness.

  • Builds a dependency graph of the whole project instead of reading files one at a time.
  • Catches vulnerabilities that only exist between files — an injection chain from an API route through a service layer into a database query.
  • Four of six pipeline stages are pure static analysis, no LLM — fast, cheap and reproducible scans.
